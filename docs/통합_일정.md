# 통합 일정 — 서비스 연결부터 부스 운영까지

## 목표

**11/13 부스에서 방문자가 직접 모의면접을 보고 리포트를 받는다.**
한 번에 한 사람씩이다. 동시 사용은 고려하지 않는다.

그 전에 **10/7 중간발표**에서 실제 조건으로 동작하는 데모를 보여준다.

---

## 최종 구성

```
[부스 노트북]                                [학과 GPU 서버]
  프론트                                       AI 서버
  백엔드 · DB · Redis    ── 요청 ──→           (전사 · 시선 분석 · Claude 호출)
          │                                        │
          │ 녹화 업로드                            │ 영상·음성 내려받기
          ▼                                        │ 질문 음성 올리기
       [AWS S3] ◀──────────────────────────────────┘
```

| 무엇을 | 어디에 | 이유 |
| --- | --- | --- |
| 프론트 | 노트북 | `localhost`로 열어야 HTTPS 없이 카메라·마이크가 켜진다 |
| 백엔드 · DB · Redis | 노트북 | 프론트와 같은 곳에 둬야 설정이 단순하다 |
| AI 서버 | 학과 서버 | 전사와 시선 분석에 GPU가 필요하다 |
| 파일 저장소 | AWS S3 | 노트북과 학과 서버가 **둘 다** 접근할 수 있어야 한다 |

**MinIO는 이 구성에서 쓸 수 없다.** MinIO는 노트북 안에서 돌기 때문에
학과 서버가 녹화 파일을 가져갈 수 없다.

---

## 전체 흐름

```
1단계 더미로 연결 ──→ 2단계 실제 모드 ──→ 3단계 중간발표 ──→ 4단계 부스
  9/25 ~ 9/30          10/1 ~ 10/4          10/5 ~ 10/7        10/8 ~ 11/13
```

**각 단계는 앞 단계가 끝나야 시작한다.** 같은 단계 안의 일은 동시에 해도 된다.
표의 「선행」 칸이 비어 있으면 그 단계가 시작되자마자 할 수 있는 일이다.

---

## 1단계 — 더미로 세 파트 연결 (9/25 ~ 9/30)

GPU도 요금도 없이 **프론트 → 백엔드 → AI가 실제로 이어지는지** 확인한다.
AI는 더미 모드라 점수와 질문 문장은 가짜지만, 요청·응답 구조는 실제와 같다.

| # | 파트 | 할 일 | 선행 |
| --- | --- | --- | --- |
| 1-1 | AI | 백엔드 미확정 10개 회신 (`백엔드_미확정사항_회신.md`) | |
| 1-2 | AI | 리포트 계약 최종본 전달 (`리포트계약_최종본_전달.md`) | |
| 1-3 | AI | 말하기 점수 연결 PR 머지. 파일 다운로드 실패를 `MEDIA_FETCH_FAILED`로 구분하는 수정 포함 | |
| 1-4 | AI | 더미 샘플 음성 주소 수정. 지금 주소가 404라 `audio_url`을 null로 바꾼다 | |
| 1-4a | AI | 기업 인재상을 `company_profile_override`로만 받도록 정리. `company_id` 조회와 `GET /ai/companies` 제거, 계약서 반영 | |
| 1-5 | 백엔드 | compose에 AI 컨테이너 추가, `APP_AI_MOCK_ENABLED=false` | 1-1 |
| 1-6 | 백엔드 | 리포트 연동 시작 (엔티티, 요청, 폴링, 저장) | 1-2 |
| 1-7 | 프론트 | 녹화 업로드 PR 머지 | |
| 1-8 | 프론트 | `audio_url`이 null이면 텍스트만 띄우는지 확인 | 1-4 |
| 1-9 | 전체 | 노트북에서 면접 한 바퀴 → 리포트 화면까지 확인 | 1-5 · 1-6 · 1-7 |

**완료 기준**: 노트북에서 면접을 끝까지 보고 리포트 화면이 뜬다. 점수는 가짜여도 된다.

**1-1과 1-2가 출발점이다.** 백엔드는 이 두 회신을 기다리고 있어서, 늦어지면 뒤가 전부 밀린다.

## 2단계 — 실제 모드로 전환 (10/1 ~ 10/4)

학과 서버 GPU와 실제 API로 **세 축 모두 진짜 점수**가 나오게 한다.

| # | 파트 | 할 일 | 선행 |
| --- | --- | --- | --- |
| 2-1 | 전체 | AWS 계정 만들고 S3 버킷 하나 생성. 누가 만들지 정한다 | |

| 2-3 | AI | 배포 이미지에 시선 라이브러리(torch · opencv · l2cs) 추가, 가중치 파일 위치 결정 | |
| 2-4 | AI | 리포트의 가짜 칸을 실제 생성으로 교체 (아래 표) | |
| 2-5 | 백엔드 | 파일 저장소를 MinIO에서 S3로 전환 | 2-1 |
| 2-6 | AI | TTS 업로드 대상을 같은 S3로 설정 | 2-1 |
| 2-7 | AI | 학과 서버에 AI 서버 띄우기 (실제 모드) | 2-2 · 2-3 |

| 2-9 | 전체 | 실제 조건으로 한 바퀴. 결과가 말이 되는지 확인 | 2-4 ~ 2-8 |

**리포트에서 아직 가짜인 칸** (2-4)

| 항목 | 지금 |
| --- | --- |
| 개선 답변 제안 | 누구에게나 같은 고정 문장 |
| 기업 인재상 코멘트 | 회사와 상관없는 고정 문장 |
| 압박 대응력 점수 | 가짜 숫자 |
| 내용 근거 (강점 · 약점) | 고정 문장 |
| 회차 비교 코멘트 | 고정 문장 |

필드 구조는 그대로이고 값만 바뀐다. 백엔드·프론트는 고칠 것이 없다.

**완료 기준**: 노트북에서 면접 → 학과 서버에서 분석 → 세 축 실제 점수가 담긴 리포트.

**비용**: 9문항 한 바퀴에 약 130원(Claude) + TTS 별도.

주제가 트러블슈팅이다. AI 파트가 낼 소재는 이렇다.

| 문제 | 해결 | 근거 |
| --- | --- | --- |
| 말은 유창한데 질문에 답하지 않은 답변이 88점 | 4단계 체크리스트 + 적절성 게이트 | 88점 → 15점 |
| Whisper가 「음」, 「어」를 지워버림 | 침묵 · 속도 변동 · 반복으로 머뭇거림 측정 | tiny · medium · large-v3 비교 |
| 응시율 100%에 만점을 주면 노려보는 사람이 1등 | 구간을 나눠 점수화 | 정면 97점 · 회피 87점 |

라이브 시연은 하지 않는다. 9문항이면 시선 분석에만 4분이 걸린다.
