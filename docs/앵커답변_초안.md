# 앵커 답변 6종 — 초안

**D 담당입니다. A가 초안만 잡아 둔 것이니 고쳐 쓰시면 됩니다.**

채점 기준을 잡기 위한 기준 답변입니다. 세 곳에 쓰입니다.

```
LLM 판정 일관성 테스트    같은 답변을 여러 번 넣어 결과가 갈리는지
적절성 게이트 확인        주제이탈 답변이 높은 총점을 받지 않는지
채점 프롬프트 예시        구간을 지키게 하는 본보기
```

**여기 있는 답변은 전부 지어낸 것입니다.** 실제 지원자의 답변이 아니라
채점기를 시험하기 위한 시험용 문항입니다.

---

## 쓰인 질문

실제로 생성된 질문 하나를 골랐습니다. 임의로 만든 질문을 쓰면
실제 채점 상황과 달라집니다.

```
카테고리   직무역량
난이도     L2 (근거 요구)
페르소나   압박형
직무       AI 엔지니어

Computer Vision은 고급, Diffusion은 중급으로 스스로 나누셨는데,
그 등급을 가른 기준이 무엇인가요?
```

이 질문이 요구하는 것은 **「등급을 가른 기준」** 하나입니다.
답변이 그 기준을 말했는지가 채점의 축입니다.

---

## 여섯 종

각 답변에 등급과 100점 구간을 붙였습니다.
**배포할 때는 이 라벨을 지웁니다.** 아래 「블라인드 배포용」을 쓰세요.

### ① 높음 — 5점 (85~100)

> 두 가지로 나눴습니다. 하나는 배포까지 해봤는가입니다. ParkCast에서
> YOLOv8n을 직접 학습시켜 배포했고, 실사 환경에서 검출률이 떨어지는 것까지
> 확인해서 원인을 좁혀봤습니다. 다른 하나는 논문을 보고 처음부터 구현할 수
> 있는가입니다. U-Net과 ViT는 논문만 보고 구현했고, 구조를 바꿔서 실험도
> 해봤습니다. Diffusion은 DDPM과 DDIM을 구현해보긴 했지만 거기서 멈췄습니다.
> 실제 문제에 적용해본 적이 없어서, 구조는 설명할 수 있어도 어떤 상황에서
> 무너지는지는 모릅니다. 그 차이가 고급과 중급을 가른 기준이었습니다.

```
왜 높음인가   기준을 두 개로 명시했고(배포 경험 · 구현 능력),
             각각에 구체적 사례가 붙어 있으며, 중급으로 낮춘 이유까지 설명한다
```

### ② 중간 — 3점 (50~69)

> 실제로 써본 경험이 얼마나 있는지로 나눴습니다. Computer Vision은
> 프로젝트에서 계속 다뤘고 논문도 여러 편 봤습니다. Diffusion도 공부는
> 했는데 아직 프로젝트에 써보지는 못했습니다. 그래서 중급으로 뒀습니다.

```
왜 중간인가   기준을 말하긴 했다("써본 경험"). 질문에 답은 했다.
             다만 "계속 다뤘다", "여러 편 봤다"처럼 근거가 얕고 구체적 사례가 없다
```

### ③ 낮음 — 2점 (30~49)

> 아무래도 Computer Vision 쪽이 더 익숙하고 자신 있어서 고급으로 적었고,
> Diffusion은 아직 배워야 할 게 많다고 생각해서 중급으로 적었습니다.
> 앞으로 더 공부해서 두 분야 모두 잘하고 싶습니다.

```
왜 낮음인가   "익숙하다", "자신 있다"는 기준이 아니라 느낌이다.
             질문이 요구한 "가른 기준"이 없다. 마지막 문장은 질문과 무관하다
```

### ④ 유창하지만 주제이탈 — 1점 (0~29)

> 제가 Computer Vision을 처음 접한 건 2학년 때였습니다. 학회에서 논문 리뷰
> 세미나를 하는데, 이미지 한 장에서 이렇게 많은 정보를 뽑아낼 수 있다는 게
> 인상적이었습니다. 그때부터 관련 논문을 스무 편 정도 읽었고, 학회 발표도
> 여러 번 했습니다. 특히 ParkCast를 하면서는 실제 서비스로 만들어보는 게
> 얼마나 다른지도 알게 됐습니다. 앞으로도 이 분야에서 계속 성장하고
> 싶다는 생각이 확고해졌습니다.

```
왜 주제이탈인가   말은 매끄럽고 길이도 충분하다. 이력서 내용도 정확하다.
                 그런데 "등급을 가른 기준"은 한 마디도 없다.
                 계기와 포부만 말했다

★ 이게 가장 중요한 앵커입니다.
  말하기와 시선 점수만으로 높은 총점을 받으면 안 되는 유형이고,
  사람도 속는 유형입니다. 채점 LLM이 여기에 30점 미만을 주는지가
  적절성 게이트가 작동하는지의 시험입니다
```

### ⑤ 짧고 불충분 — 2점 (30~49)

> 경험 차이입니다. Computer Vision을 더 많이 다뤄봐서요.

```
왜 이 등급인가   짧지만 질문에는 답했다("경험 차이").
                짧다는 이유만으로 주제이탈로 내리면 안 된다.
                길이는 말하기 축에서 따로 본다
```

### ⑥ 흐지부지 마무리 — 4점 (70~84)

> 기준은 두 가지였는데요, 하나는 배포까지 해봤느냐입니다. ParkCast에서
> YOLOv8n을 학습시켜서 HuggingFace Spaces에 올려봤고, 거기서 도메인 갭
> 문제도 겪었습니다. 그리고 또 하나는... 논문 구현 쪽인데, U-Net이나 ViT를
> 직접 구현해본 게 있어서 그게 좀... 네, 그래서 그렇게 나눴습니다.

```
왜 이 등급인가   내용은 ①에 가깝다. 기준 두 개를 말했고 사례도 있다.
                다만 두 번째 기준을 끝맺지 못했다.
                내용 점수는 양호이고, 마무리는 말하기 축에서 감점된다

처음에는 3점(50~69)으로 잡았다가 4점으로 올렸다.
말이 끊긴 것은 말하기 축의 문제이지 내용의 문제가 아니다.
같은 것을 두 축에서 두 번 깎으면 안 된다
```

## 블라인드 배포용

**아래를 그대로 복사해서 세 명에게 보내세요.** 순서를 섞었고 라벨을 지웠습니다.

```
질문
Computer Vision은 고급, Diffusion은 중급으로 스스로 나누셨는데,
그 등급을 가른 기준이 무엇인가요?

아래 여섯 답변에 1~5점을 매겨 주세요.
질문이 요구한 것을 실제로 다뤘는지만 봅니다.
말솜씨, 길이, 자신감은 보지 않습니다.

  5점  질문에 정면으로 답했고 구체적 사례와 근거가 있다
  4점  질문에 답했으나 근거가 얕거나 사례가 일반적이다
  3점  질문의 핵심을 다뤘으나 겉돈다
  2점  질문의 핵심을 비껴갔다
  1점  질문이 요구한 것을 다루지 않았다


A. 제가 Computer Vision을 처음 접한 건 2학년 때였습니다. …(④ 전문)

B. 경험 차이입니다. Computer Vision을 더 많이 다뤄봐서요.

C. 두 가지로 나눴습니다. 하나는 배포까지 해봤는가입니다. …(① 전문)

D. 아무래도 Computer Vision 쪽이 더 익숙하고 자신 있어서 …(③ 전문)

E. 기준은 두 가지였는데요, 하나는 배포까지 해봤느냐입니다. …(⑥ 전문)

F. 실제로 써본 경험이 얼마나 있는지로 나눴습니다. …(② 전문)
```

정답은 이렇습니다. **배포할 때는 빼세요.**

```
A → ④ 주제이탈 (1점)      B → ⑤ 짧고 불충분 (2점)
C → ① 높음 (5점)          D → ③ 낮음 (2점)
E → ⑥ 흐지부지 (4점)      F → ② 중간 (3점)
```

---

## 라벨과 점수의 대응

사람이 매기는 1~5점과 코드가 쓰는 0~100점을 잇는 표입니다.
**이 표가 없으면 「중간은 관대하게」 합의해 놓고도 코드는 게이트를 걸어버립니다.**

```
5점 우수       85~100
4점 양호       70~84
3점 중간       50~69     게이트 없음
2점 미흡       30~49     총점 상한 70
1점 주제이탈    0~29      총점 상한 40
```

지금 코드의 게이트 경계가 이미 30과 50이라 **이 표대로 가면 코드를 고칠 필요가 없습니다.**
대신 **같은 표를 채점 프롬프트에 그대로 넣어야 합니다.**
안 넣으면 LLM이 자기 기준으로 점수를 매겨 또 어긋납니다.

## 이 세트로 다음에 하는 것

### 1. 블라인드 라벨링

세 명이 매긴 등급이 위 정답과 다르면 **답변을 고칩니다.**
사람 판단을 바꾸는 게 아니라 답변이 애매하게 쓰였다는 뜻입니다.
10분이면 끝납니다.

### 2. LLM 판정 일관성 테스트

여섯 개를 각각 다섯 번씩, 총 30번 채점기에 넣습니다.

```
확인할 것   같은 답변이 매번 같은 구간에 들어가는가
합격 기준   여섯 개 모두 다섯 번이 같은 구간에 들어간다
불합격이면  verdict 2단계 판정을 켜지 않습니다.
           같은 사람이 같은 답변으로 다른 리포트를 받게 됩니다
```

비용은 30번 × 약 5원 = **150원 안팎**입니다.

### 3. 적절성 게이트 확인

**④ 주제이탈 답변이 30점 미만을 받는지**가 전부입니다.

이 세트는 이미 한 번 돌려봤습니다. **처음에는 실패했습니다.**

```
              의도       1차      2차
A 주제이탈     0~29      88  ✗     15  ✓
B 짧고 불충분  30~49     25  ✗     35  ✓
C 높음        85~100    95  ✓     92  ✓
D 낮음        30~49     20  ✗     30  ✓
E 흐지부지     70~84     82  ✓     72  ✓
F 중간        50~69     60  ✓     58  ✓
```

1차에서 A가 88점을 받았습니다. 채점기가 남긴 근거는 이랬습니다.

> 정작 등급을 가른 **'기준' 자체는 명시하지 않았다** — 그러고 88점

**답이 없다고 스스로 판단하고도 사례가 많다는 이유로 높은 점수를 줬습니다.**

프롬프트를 두 단계로 나눠 고쳤더니 15점으로 내려왔습니다.
1단계에서 「질문이 요구한 것이 있는가」만 보고, 없으면 거기서 끝냅니다.
**이 순서를 지우면 88점이 그대로 돌아옵니다.**

### 4. 채점기 연결

프롬프트가 확정되면 한 줄이면 붙습니다.

```python
report_dummy.CONTENT_SCORER = scorer   # (질문, 답변) -> 0~100
```

프롬프트 초안은 `docs/내용채점_프롬프트_초안.md`에 있습니다.

## 고쳐 쓰실 때

- **답변을 더 길게 쓰지 마세요.** 실제 면접 답변은 45~60초, 300자 안팎입니다.
  앵커가 실제보다 길면 채점기가 길이에 반응하게 됩니다.
- **여섯 개를 같은 질문으로 유지하세요.** 질문이 다르면 등급 차이가
  답변 때문인지 질문 때문인지 구분되지 않습니다.
- **④를 약하게 만들지 마세요.** 읽자마자 딴소리인 게 티 나면 시험이 되지 않습니다.
  말은 잘하는데 답이 없어야 합니다.
