# AI 파트 할 일

AI 파트가 맡은 일만 순서대로 정리합니다. 다른 파트의 일은 각 파트가 정합니다.

계약 기준은 **노션 「최종 계약본 (더미서버+리포트계약)」 토글과 거기 달린 댓글**입니다.
노션 칸이 차서 본문에 못 넣은 최신 내용은 이 레포 `docs/`의 계약서에 있습니다.

---

## 목표

- **중간발표**: 실제 조건(GPU · Claude · 실제 영상)으로 도는 데모 영상
- **부스**: 방문자가 직접 면접을 보고 리포트를 받는다. 한 번에 한 사람

## 순서

담당은 AI 안의 역할로 적었습니다.

```
연동   질문 생성 · 리포트 · 백엔드 연동
STT    전사 · 말하기 점수 · 질문 음성(TTS)
시선   시선 분석 · GPU 서버
채점   내용 채점 기준
```

### 1. 백엔드가 더미 서버를 붙일 수 있게

| # | 할 일 | 담당 |
| --- | --- | --- |
| 1-1 | 백엔드 미확정 10개 회신 (`백엔드_미확정사항_회신.md`) | 연동 |
| 1-2 | 리포트 계약 — 노션 이후 바뀐 값 전달 (`리포트계약_최종본_전달.md`) | 연동 |
| 1-3 | PR #14 머지 | 연동 |
| 1-4 | 더미 질문 음성을 null로. 지금 샘플 주소가 404 | 연동 |

붙이는 작업(compose, 설정)은 백엔드가 합니다. 막히면 같이 봅니다.

### 2. 리포트의 고정 문장을 실제 생성으로

방문자가 직접 보는 화면이라, 본인 답변과 상관없는 문장이 나오면 바로 티가 납니다.

| 항목 | 지금 |
| --- | --- |
| 개선 답변 제안 | 누구에게나 같은 문장 |
| 기업 인재상 코멘트 | 회사와 상관없는 문장 |
| 압박 대응력 점수 | 가짜 숫자 |
| 내용 근거 (강점 · 약점) | 고정 문장 |
| 회차 비교 코멘트 | 고정 문장 |

담당: 연동. 필드 구조는 그대로라 백엔드 · 프론트는 고칠 것이 없습니다.
리포트 한 건 비용이 10~20원 늘어납니다. 실제 호출 전에 비용을 확인받습니다.

### 3. 학과 서버에 실제 모드로 띄우기

| # | 할 일 | 담당 |
| --- | --- | --- |
| 3-1 | 학과 서버 점검: 오래 띄워도 되는지, GPU를 같이 쓰는지, 외부 인터넷 되는지 | 시선 |
| 3-2 | 배포 이미지에 시선 라이브러리(torch · opencv · l2cs) 추가, 가중치 파일 위치 | 시선 |
| 3-3 | 질문 음성 업로드 경로를 백엔드 설계에 맞추기 | STT |
| 3-4 | 학과 서버에 AI 서버 띄우기, 노트북에서 SSH 터널로 연결 확인 | 시선 |
| 3-5 | 실제 조건으로 한 바퀴. 결과가 말이 되는지 확인 (약 130원, 사전 허락) | 연동 |

**3-3이 왜 필요한가.** 백엔드는 AI가 `sessions/{sessionId}/questions/{questionId}.mp3`에만
쓸 수 있게 권한을 막는 설계입니다. 지금 AI는 `tts/{랜덤}.mp3`에 올려서, 실제 S3에서는
업로드가 거부됩니다.

### 4. 중간발표

| 할 일 | 담당 |
| --- | --- |
| 3-5 결과를 녹화해 데모 영상으로 | 연동 |
| AI 트러블슈팅 슬라이드 | AI 전원 |

| 문제 | 해결 | 근거 |
| --- | --- | --- |
| 말은 유창한데 질문에 답하지 않은 답변이 88점 | 4단계 체크리스트 + 적절성 게이트 | 88점 → 15점 |
| Whisper가 「음」, 「어」를 지워버림 | 침묵 · 속도 변동 · 반복으로 머뭇거림 측정 | tiny · medium · large-v3 비교 |
| 응시율 100%에 만점을 주면 노려보는 사람이 1등 | 구간을 나눠 점수화 | 정면 97점 · 회피 87점 |

### 5. 부스 준비

| 할 일 | 담당 |
| --- | --- |
| 인성 질문 채점 기준 보완 (자기소개 · 강점 질문이 60점을 넘기 어려움) | 채점 |
| 행사 당일 학과 서버를 쓸 수 있는지 확인 | 시선 |
| AI 서버가 멈췄을 때 더미 모드로 바로 바꾸는 절차 | 연동 |
| 팀 리허설에서 AI 쪽 점검 | AI 전원 |

## 다른 파트와 맞춰야 하는 것

AI가 GPU 때문에 **다른 컴퓨터(학과 서버)에서 돈다**는 사정 하나에서 나오는 것들입니다.
3단계를 시작하기 전에 백엔드에 알립니다.

| 무엇을 | 누구와 | 왜 |
| --- | --- | --- |
| AI 서버 주소가 학과 서버가 된다 | 백엔드 | 백엔드가 부를 주소가 바뀜 |
| 녹화 파일이 학과 서버에서 내려받을 수 있는 곳에 있어야 한다 | 백엔드 | 노트북 안의 MinIO는 학과 서버가 못 닿음 |
| 질문 음성을 프론트가 어떻게 재생할지 | 백엔드 | AI는 일반 S3 주소를 주는데 버킷은 비공개라 403 |

세 번째만 **같이 정해야 하는 문제**입니다. 나머지 둘은 알리기만 하면 됩니다.
