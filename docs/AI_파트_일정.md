# AI 파트 할 일

AI 파트가 맡은 일만 순서대로 정리합니다. 다른 파트의 일은 각 파트가 정합니다.

계약 기준은 **노션 「최종 계약본 (더미서버+리포트계약)」 토글과 거기 달린 댓글**,
그리고 노션 「인프라 관련 확인 질문」입니다.

---

## 목표

- **중간발표**: 실제 조건(GPU · Claude · 실제 영상)으로 도는 데모 영상
- **부스**: 방문자가 직접 면접을 보고 리포트를 받는다. 한 번에 한 사람

---

## 지금 상태

| | 상태 |
| --- | --- |
| 질문 생성 · 꼬리질문 · 되묻기 | ✅ 실제 동작 |
| 리포트 세 축 점수 (내용 · 말하기 · 시선) | ✅ 실제 점수. 가중치 확정 |
| 백엔드 연동 코드와의 호환 | ✅ 백엔드 요청 모양 그대로 보내 봄. 어긋나는 필드 0개 |
| 기업 인재상 (override 전용) | ✅ 노션 댓글 합의대로 |
| 더미 질문 음성 | ✅ null (없는 샘플 주소를 주던 것 수정) |
| 리포트의 일부 칸 | ❌ 고정 문장 |
| 배포 | ❌ 아직 로컬에서만 돎 |

더미 서버 연결은 백엔드가 합니다. 필요한 정보는 노션에서 이미 전달했습니다.

## 순서

```
연동   질문 생성 · 리포트 · 백엔드 연동
STT    전사 · 말하기 점수 · 질문 음성(TTS)
시선   시선 분석 · GPU 서버
채점   내용 채점 기준
```

### 1. 리포트의 고정 문장을 실제 생성으로 — 연동

방문자가 직접 보는 화면이라, 본인 답변과 상관없는 문장이 나오면 바로 티가 납니다.

| 항목 | 지금 |
| --- | --- |
| 개선 답변 제안 | 누구에게나 같은 문장 |
| 기업 인재상 코멘트 | 회사와 상관없는 문장 |
| 압박 대응력 점수 | 가짜 숫자 |
| 내용 근거 (강점 · 약점) | 고정 문장 |
| 회차 비교 코멘트 | 고정 문장 |

필드 구조는 그대로라 백엔드 · 프론트는 고칠 것이 없습니다.
리포트 한 건 비용이 10~20원 늘어납니다. 실제 호출 전에 비용을 확인받습니다.

### 2. 학과 서버에 실제 모드로 띄우기

| # | 할 일 | 담당 |
| --- | --- | --- |
| 2-1 | 학과 서버 점검: 오래 띄워도 되는지, GPU를 같이 쓰는지, 외부 인터넷 되는지 | 시선 |
| 2-2 | 배포 이미지에 시선 라이브러리(torch · opencv · l2cs) 추가, 가중치 파일 위치 | 시선 |
| 2-3 | 질문 음성 업로드 경로를 백엔드 설계(`sessions/{sessionId}/questions/{questionId}.mp3`)에 맞추기 | STT · 연동 |
| 2-4 | 학과 서버에 AI 서버 띄우기. 접속 정보와 다시 켜는 방법 공유. API 키는 연동이 직접 넣음 | 시선 |
| 2-5 | 백엔드에 알리기 (아래 「실제 모드 전에 백엔드와」) | 연동 |
| 2-6 | 실제 조건으로 한 바퀴. 결과가 말이 되는지 확인 (약 130원, 사전 허락) | 연동 |

### 3. 중간발표

| 할 일 | 담당 |
| --- | --- |
| 2-6 결과를 녹화해 데모 영상으로 | 연동 |
| AI 트러블슈팅 슬라이드 | AI 전원 |

| 문제 | 해결 | 근거 |
| --- | --- | --- |

## 실제 모드 전에 백엔드와

AI가 GPU 때문에 **학과 서버에서 따로 돈다**는 사정에서 나오는 것들입니다.
지금은 알릴 필요가 없고, 2단계를 시작할 때 짧게 전합니다.
자세한 내용은 `백엔드_인프라답변_변경사항.md` 「실제 모드」에 있습니다.

| 무엇을 | 왜 |
| --- | --- |
| AI 서버 주소가 학과 서버가 된다 | 백엔드가 `APP_AI_BASE_URL`만 바꾸면 됨 |
| 녹화 파일을 S3에 둬야 한다 | 노트북 안의 MinIO는 학과 서버가 못 닿음 |
| 질문 음성 재생 방식을 정해 달라 | AI는 서명 없는 S3 주소를 주는데 버킷은 비공개라 403 |
| S3 버킷 이름과 AI용 쓰기 권한(키)을 받는다 | 2-3 테스트 · 2-6에 필요 |

백엔드가 리포트 연동을 시작하면 `리포트계약_최종본_전달.md`를 전합니다.
