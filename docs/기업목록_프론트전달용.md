# 기업 목록 — 프론트 UI용

면접 시작 화면에서 지원 기업을 고르는 UI에 쓰시면 됩니다.
고른 기업의 인재상이 질문 생성에 반영됩니다.

---

## 어디서 가져오나

```
GET /ai/companies
X-Cueanda-Secret: <공유 시크릿>
```

```json
{
  "companies": [
    { "company_id": "naver", "name": "네이버", "industry": "IT/플랫폼" },
    { "company_id": "kakao_mobility", "name": "카카오모빌리티", "industry": "모빌리티/플랫폼" }
  ]
}
```

**필드는 이 세 개가 전부입니다.** 인재상 원문은 내려가지 않습니다.
질문을 만들 때 AI 서버 안에서만 씁니다.

## 고른 뒤에 할 일

세션을 만들 때 `company_id`를 같이 보내주세요.

```json
POST /ai/sessions
{
  "job_role": "백엔드 개발",
  "question_count": 9,
  "persona": "friendly",
  "company_id": "naver"
}
```

```
안 보내도 됩니다      기업 무관하게 직무만으로 질문이 나옵니다
직접 입력을 받으려면   company_profile_override에 텍스트를 넣으면
                     company_id보다 우선합니다
```

## 알아두실 것

### 목록에 없는 기업이 있습니다

공식 채용 페이지에서 인재상을 확인한 기업만 내려갑니다.
수집은 했지만 출처를 확정하지 못한 기업은 목록에서 빠집니다.
확인되지 않은 내용으로 질문을 만들면 사용자에게 틀린 정보가 나가기 때문입니다.

삼성전자, 토스처럼 유명한 기업이 안 보일 수 있는데 버그가 아닙니다.
확인이 끝나면 목록에 추가됩니다.

### 검색이 필요할 만한 개수입니다

21개라 드롭다운으로도 되지만, 앞으로 늘어납니다.
검색 입력창을 같이 두시는 편이 낫습니다. `name`으로 거르시면 됩니다.

### 산업(industry)은 보조 정보입니다

같은 이름의 계열사를 구분하는 용도입니다. 필수로 보여주실 필요는 없습니다.
