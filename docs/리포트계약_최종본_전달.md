# 리포트 계약 — 노션 최종본 이후 바뀐 것

리포트 계약은 노션 「최종 계약본 (더미서버+리포트계약)」 토글 안의
**리포트생성_API계약_백엔드전달용**이 기준입니다. 이 문서로 파싱 코드를 만드셔도 됩니다.

노션 칸이 다 차서 본문에 못 넣은 변경만 정리했습니다.
AI 레포 `docs/리포트생성_API계약_백엔드전달용.md`에는 반영돼 있습니다.
**응답 구조는 바뀌지 않았고 값만 바뀌었습니다.**

---

## 바뀐 것

| 항목 | 노션 최종본 | 지금 |
| --- | --- | --- |
| 축 가중치 | 0.5 / 0.3 / 0.2, 잠정 | **0.5 / 0.25 / 0.25, 확정** |
| 시선 실패 시 재정규화 | 0.625 / 0.375 | **0.667 / 0.333** |
| 말하기 `metrics` | 빈 객체 | **키 3개 확정** |
| `MEDIA_FETCH_FAILED` | 에러 표에만 있음 | **실제로 나감** |

### 말하기 `metrics`

```json
"speech": {
  "status": "ok",
  "score": 61,
  "display": 4,
  "metrics": {
    "hesitation_score": 32,
    "speech_rate_cv": 0.284,
    "repetition_count": 3
  }
}
```

```
hesitation_score   0~100 정수. 클수록 많이 머뭇거렸다. 화면에 쓸 대표 지표
speech_rate_cv     말 빠르기가 들쭉날쭉한 정도
repetition_count   바로 이어서 같은 말을 반복한 횟수
```

「음」, 「어」는 세지 않습니다. Whisper가 지워 버려서 안정적으로 잡히지 않아,
침묵 · 속도 변동 · 반복을 묶어 「머뭇거림」으로 나타냅니다.
내용 · 시선 축 `metrics`는 아직 빈 객체입니다.

### `MEDIA_FETCH_FAILED`

전에는 답변 파일을 못 받아도 `STT_FAILED`로 나가서, 계약서의
「새 presigned URL로 1회 재시도」가 동작할 수 없었습니다. 이제 따로 나갑니다.
대개 presigned URL 만료가 원인입니다.

노션 계약서에 다 있는 내용이지만, `13-report.md`에 질문으로 남아 있어서 짧게 답합니다.

## 서비스가 제대로 돌려면 필요한 것

계약서에 있는 내용 중 실제로 돌릴 때 걸리기 쉬운 두 가지입니다.

- **영상 · 음성 presigned URL 만료는 30분 이상**이어야 합니다. 리포트는 영상을 받아
  분석하는 데 몇 분이 걸려서, 짧으면 도중에 `MEDIA_FETCH_FAILED`가 납니다.
- **`is_replay` · `is_spare_topic`을 요청에 실어 주셔야** 회차 비교가 됩니다.
  빠지면 `by_question`이 항상 빈 배열입니다.
