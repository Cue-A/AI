# 내용 채점 프롬프트 초안

**D 담당입니다. A가 초안만 잡아 둔 것이니 고쳐 쓰시면 됩니다.**

지금 내용 점수는 `report_dummy.score_for()`가 해시로 만드는 가짜 값입니다.
답변 텍스트가 있어야 진짜 채점이 되는데 STT가 아직 안 붙어서 연결하지 못했습니다.
붙는 날 바로 쓸 수 있도록 문구만 미리 잡아 뒀습니다.

---

## 왜 구간표가 프롬프트에 들어가야 하나

우리가 블라인드로 매긴 건 1~5점이고, 코드가 쓰는 건 0~100점입니다.
둘을 잇는 표를 프롬프트에 넣지 않으면 LLM이 자기 기준으로 점수를 매깁니다.

그러면 우리가 3점(중간)이라고 본 답변에 LLM이 45점을 줘서
게이트에 걸립니다. 관대하게 가기로 한 합의와 어긋나게 됩니다.

## 제일 조심할 것 — 실제로 실패한 지점입니다

**채점 LLM은 사례가 많으면 점수를 후하게 줍니다.**

앵커 6종으로 실제로 돌려봤더니, 「유창하지만 주제이탈」 답변이 **88점**을
받았습니다. 그 답변은 이력서 내용을 정확히 말하고 사례도 풍부하지만
질문이 물은 「기준」은 한 마디도 없습니다.

더 심각한 것은 채점기가 남긴 근거입니다.

> 정작 등급을 가른 **'기준' 자체는 명시하지 않았다** — 그러고 88점

**스스로 답이 없다고 판단하고도 높은 점수를 줬습니다.**
사례의 양에 반응한 것입니다.

그래서 채점을 **두 단계로 강제**합니다. 먼저 질문이 요구한 것이 있는지만
보고, 없으면 거기서 끝냅니다. 사례를 보는 것은 그다음입니다.
**이 순서를 지우면 88점이 그대로 돌아옵니다.**

---

## 프롬프트 초안

```
당신은 면접 답변의 내용을 채점합니다.

질문이 요구한 것을 답변이 실제로 다뤘는지만 봅니다.
말솜씨, 발음, 자신감은 보지 않습니다. 그것은 말하기 축에서 따로 봅니다.

채점은 두 단계입니다. 순서를 바꾸지 마세요.


1단계 — 질문이 요구한 것이 답변에 있는가

  질문이 「기준」을 물었으면 기준이,
  「이유」를 물었으면 이유가,
  「어떻게 했는지」를 물었으면 방법이 답변에 있어야 합니다.

  없으면 여기서 0~29점으로 끝냅니다. 2단계로 넘어가지 않습니다.
  사례가 아무리 많아도, 말이 아무리 매끄러워도, 이력서 내용이
  아무리 정확해도 마찬가지입니다.

  계기 · 포부 · 경험담은 질문이 그것을 묻지 않았다면 답이 아닙니다.
  「이 답변에서 질문에 대한 답을 한 문장으로 뽑을 수 있는가」를
  스스로 물어보고, 뽑을 수 없으면 0~29입니다.


2단계 — 1단계를 통과했으면 근거의 두께를 봅니다

  30~49   요구한 것을 말하긴 했으나 느낌 · 인상 수준이다
          「익숙해서」, 「자신 있어서」처럼 판단 과정이 없다
  50~69   말했고 관련도 있으나 구체적 사례가 없다
  70~84   말했고 사례가 있으나 일반적이거나 설명이 덜 끝났다
  85~100  말했고 구체적 사례와 판단 과정이 함께 있다


규칙

- 짧다는 이유만으로 낮게 주지 않습니다. 한 문장이어도 질문에 답했으면
  1단계를 통과합니다. 길이는 말하기 축에서 따로 봅니다.
- 말이 끊기거나 흐지부지 끝난 것은 내용 점수에 반영하지 않습니다.
  그것도 말하기 축에서 봅니다.
- 답변에 없는 내용을 추측해서 채워 읽지 않습니다.
  「아마 이런 뜻이었을 것이다」로 점수를 올리지 않습니다.
- 근거를 쓸 때는 답변에서 실제로 인용할 수 있는 부분만 씁니다.

출력은 점수(0~100 정수)와 한 문장 근거입니다.
```

## 앵커 답변을 예시로 붙이면 더 안정됩니다

D가 만든 앵커 답변 여섯 종 중 두세 개를 프롬프트에 예시로 넣으면
구간이 훨씬 잘 지켜집니다. 특히 이 둘은 꼭 넣는 게 좋습니다.

```
유창하지만 주제이탈   →  0~29 구간의 본보기
짧고 불충분          →  짧다고 낮게 주면 안 된다는 본보기
```

## 켜기 전에 확인할 것

**같은 답변을 여러 번 넣어서 점수가 갈리는지 봐야 합니다.**
갈리면 같은 사람이 같은 답변으로 다른 리포트를 받게 됩니다.

앵커 여섯 종을 각각 다섯 번씩 돌려서 구간을 벗어나지 않으면 켭니다.

## 연결 지점

STT가 붙으면 `ai/report_dummy.py`의 이 부분을 교체하면 됩니다.

```python
scores = {a: score_for(session_id, r.question_id, a) for a in AXES}
```

`content`만 실제 채점 결과로 바꾸고 나머지 축은 그대로 두면
게이트 · 재정규화 · 회차 비교는 손대지 않아도 동작합니다.
